# OKF Framework and Databases

The `OKF` directory contains two subdirectories which are in Open Table Format (OKF 0.2):

- `OKF/okf_bundle_dbc_1720`
- `OKF/okf_bundle_pdcrinfo_1720`

## Teradata Databases
These directories represent two Teradata databases containing Teradata system metadata:
- **dbc**: The data dictionary.
- **pdcrinfo**: Historic metadata from `dbc` that is tracked daily.

## Project Objective
This project is to extract OKF format data based on the latest definition of Open Knowledge Format. The specification can be found here: [OKF Specification](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md).
